# mongsil-bot

이터널 리턴 전적을 조회하는 Discord 봇(몽실봇). 닉네임만으로 랭크·전적·플레이타임을 디스코드 안에서 바로 확인한다.

## 주요 기능

- `/랭크` — 티어·RP, 순위·상위 %, 승률, 평균 순위, 모스트 캐릭터
- `/랭킹` — KR 서버 Top 100 (버튼 페이지네이션)
- `/이터컷` — 이터니티·데미갓 RP 컷
- `/플탐` — 최근 7일 플레이타임 통계
- `/시즌`, `/동접` — 현재 시즌 정보, 실시간 동시 접속자 수(Steam)
- 커스텀 이모지 단독 메시지를 자동 확대(웹훅)

## 동작 방식

bser Open API를 폴링해 조회하고 시즌은 자동 감지한다. 응답은 discord.py Components V2 UI로 렌더한다. API 클라이언트는 LRU 캐시·동시성 제한·429 백오프 재시도를 갖춘다.

## 기술 스택

Python, discord.py, aiohttp. 데이터 소스는 bser Open API·Steam Web API. NAS(PMC) 상시 구동.
